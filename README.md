# Fast Clip
A simple video editor, helps you create clips fast and eazy.

## Features
- **FAST**: We use real time design, which can open big video files without prescanning.
- **PERFORMANCE**: Powered by rust and gpui, bring fast software reaction.
- **COMPATIBILITY**: Based on ffmpeg, bring good compatibility with video formats.
